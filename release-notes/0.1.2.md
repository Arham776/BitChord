### What's changed
- Recommendation queues now refresh on deliberate listening actions and refill only when fewer than three tracks remain, keeping natural song transitions steady.
- Removing tracks from the queue no longer triggers an immediate refresh; Automix can still reorder queued tracks.
- Google sign-in follows Google's own flow without BitChord intercepting password or passkey steps.
- The macOS sidebar toggle stays visible, Recents loading layouts adapt to larger screens, and closing Now Playing returns to the same screen and position.

### macOS download
This Apple Silicon build is ad-hoc signed and is not notarized by Apple. macOS may block its first launch.

Only continue if you downloaded BitChord from the official BitChord GitHub release and trust it.

**System Settings:** Move BitChord to Applications and try to open it once. If macOS blocks it, open System Settings → Privacy & Security, scroll to Security, choose **Open Anyway** for BitChord, then confirm **Open** in the warning dialog.

**Terminal:** After moving BitChord to Applications, open Terminal and run:
```sh
xattr -dr com.apple.quarantine "/Applications/BitChord.app"
open "/Applications/BitChord.app"
```
This removes the downloaded-file quarantine attribute from the app bundle so Gatekeeper no longer blocks this launch.
